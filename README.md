# WANG Hejun — Personal Website

Academic personal website for **WANG Hejun (Martin)**, a PhD student in Computing at The Hong Kong Polytechnic University.

## Structure

- `index.html` — page content and metadata
- `styles.css` — responsive visual system, layout, and dark mode
- `script.js` — navigation, theme persistence, and reveal interactions
- `figs/head.jpg` — profile portrait
- `favicon.svg`, `robots.txt`, `sitemap.xml` — site and search metadata

The website is deployed through GitHub Pages from the `main` branch and is available at [baiyebutingxuan.github.io](https://baiyebutingxuan.github.io/).
