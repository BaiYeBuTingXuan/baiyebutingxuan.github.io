# WANG Hejun — Personal Website

A clean academic personal homepage for **WANG Hejun (Martin)**, a PhD student in Computing at The Hong Kong Polytechnic University. The site is intentionally built with plain HTML and CSS so that the content is easy to update without a build step.

The main content is in `index.html`. Search for the comments **EDIT INTRODUCTION**, **EDIT NEWS**, and **EDIT RECENT WORK** to update those sections. Styling is in `styles.css`, while `script.js` only updates the copyright year.

The current font pairing is **Source Serif 4** for the name and section headings, and **Inter** for navigation and body text. Both are loaded from Google Fonts in `index.html`; their CSS variables are defined at the top of `styles.css`.

Each research entry in **Recent Work** is a `publication` block. Keep the paper image, complete paper title, authors, venue, and labeled **Website**, **arXiv**, and **GitHub** links when adding a new item.

The website is deployed through GitHub Pages from the `main` branch at [baiyebutingxuan.github.io](https://baiyebutingxuan.github.io/).
